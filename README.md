# Отчёт ПТО — ГК КРАШМАШ

План / факт выполнения работ по объектам, журнал КС-2 / КС-3, поступления денег, гарантийные удержания.
Отдельная система, устроена так же, как «Рапорт прораба».

- `index.html` — страница ПТО (ввод КС, денег, плана, объектов). Открывается по ссылке ПТО.
- `director.html` — сводка для руководителя (только просмотр). Открывается по ссылке руководителя.
- `apps-script/Code.gs` — скрипт базы (Google Таблица «База ПТО»). Ключи в репозитории не хранятся.
- Исходники — `src/`, сборка `python3 src/build.py`.
- Расчёты (`src/calc.js`) повторяют формулы старого Excel-отчёта ПТО; сверка: `node tools/check.js data.json ref.json`.
- Перенос из старого Excel: `python3 tools/import_xlsx.py старый.xlsx папка` → `База_ПТО.xlsx`.
- Проверка без Google: `node tools/mockserver.js data.json` → `http://localhost:8080/index.html#u=http://localhost:8080/exec&k=pto`.
