Как заполнять

  1. Раз в месяц — вкладка «План»: план выполнения по каждому объекту на месяц.
  2. По каждой КС — «Журнал КС» → «+ Новая КС»: дата, объект, № КС, сумма КС-2. Отчётный месяц подставится по дате сам; «К оплате КС-3» — если пусто, считается по % удержания договора.
  3. По мере движения КС открывайте ту же КС и меняйте статусы: согласование → подписание → оплата, после оплаты — дата оплаты. Новую строку для той же КС не заводите — будет двойной счёт.
  4. Деньги от заказчика — «Деньги» → «+ Поступление», по выписке банка.
  5. В конце месяца начальник ПТО пишет «Главное за месяц» (здесь, выше).
  6. Новый объект — «Объекты» → «+ Объект». Объект закрыт — статус «Завершён», не удалять.
Все изменения пишутся в Google Таблицу «База ПТО» и на лист «Журнал изменений» (кто и когда).
